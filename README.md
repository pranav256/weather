# Weather App

A minimal, real-time weather forecast client built with vanilla JavaScript and the OpenWeatherMap REST API.

## Features

- **City Search:** Asynchronous weather lookups by city name with loading states.
- **Metrics:** Displays temperature (Celsius/Fahrenheit), atmospheric humidity, wind speed, and weather condition descriptions.
- **Dynamic Theming:** Adjusts interface appearance based on retrieved weather conditions.

## Tech Stack

- Vanilla JavaScript (Fetch API, Async/Await)
- OpenWeatherMap API
- HTML5 & CSS3

## Setup

1. Obtain a free API key from [OpenWeatherMap](https://openweathermap.org/api).
2. Insert your key into the API configuration in `app.js`.
3. Open `index.html` in your browser.
